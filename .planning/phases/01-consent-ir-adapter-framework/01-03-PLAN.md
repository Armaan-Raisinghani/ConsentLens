<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User config (consentlens.config.json) → Plugin system | User-controlled config drives plugin registration |
| Community rule packs → Rule pack parser | Third-party JSON rule packs parsed and executed |
| Custom plugin factories → AdapterRegistry | Third-party code executes with DOM access |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-11 | Tampering | Rule pack JSON | high | mitigate | Zod schema validation on import; version/publisher verification in Phase 2 |
| T-01-12 | Elevation of Privilege | Custom plugin factories | high | mitigate | Plugins run in same origin as extension; no elevated permissions; sandbox in Phase 5 |
| T-01-13 | Spoofing | Provider config spoofing | medium | mitigate | Core providers hardcoded; user-added providers validated against known patterns |
| T-01-14 | Information Disclosure | Config export contains settings | low | accept | Config is user data; export is user-initiated; no secrets in config |
| T-01-15 | Denial of Service | Malicious rule pack (complex regex) | medium | mitigate | Regex timeout via RE2 or timeout wrapper in Phase 2 engine |

</threat_model>
