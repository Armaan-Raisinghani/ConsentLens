<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Page DOM → CookieAdapter | Untrusted cookie data parsed and classified |
| r.jina.ai → Policy/Terms adapters | External CORS proxy fetches policy/terms content |
| Tracker lists → CookieAdapter | Third-party tracker lists determine cookie categories |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-06 | Spoofing | CookieAdapter classification | medium | mitigate | Bundle tracker lists at build time; version pin; integrity hash verification |
| T-01-07 | Tampering | r.jina.ai response | high | mitigate | Validate response structure; timeout; fallback to direct fetch if CORS allows; cache with Cache-Control (D-21) |
| T-01-08 | Information Disclosure | Policy/Terms content fetch | medium | mitigate | Only fetch user-navigated pages; no background crawling; respect robots.txt in later phases |
| T-01-09 | Denial of Service | Tracker list size / parsing | low | accept | Lists ~50KB compressed; parse at build time, not runtime |
| T-01-10 | Elevation of Privilege | Mutable context enrichment | low | mitigate | Context is page-scoped; no cross-origin leakage; enrichment only adds provider hint |

</threat_model>
