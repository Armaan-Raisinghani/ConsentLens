## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Spoofing | OAuthAdapter detection | medium | mitigate | Validate extracted provider against known provider list (D-15); reject unknown providers |
| T-01-02 | Tampering | Plugin registerAdapter | high | mitigate | Plugin interface validates factory signature; registry runs adapters in isolated try/catch (D-12) |
| T-01-03 | Repudiation | Evidence references | low | accept | Evidence includes extractionMethod and timestamp for auditability (D-09) |
| T-01-04 | Information Disclosure | OAuth scope extraction | low | mitigate | Scopes only extracted from page DOM; no network requests in Phase 1 |
| T-01-05 | Denial of Service | AdapterRegistry priority loop | low | mitigate | Each adapter wrapped in try/catch; timeout via AbortSignal in later phases |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | package-legitimacy gate + blocking human checkpoint for [ASSUMED]/[SUS] packages |

</threat_model>

- `Evidence` — interface with source, selector?, url?, text?, confidence, extractionMethod, extractedAt
- `DecisionRecord` — interface with matchedRule, aiClassification, confidence, provenance

- `OAuthAdapter` — class implementing Adapter, priority=10
- `AdapterRegistry` — class with register(adapters), run(context): Promise<AdapterResult>
