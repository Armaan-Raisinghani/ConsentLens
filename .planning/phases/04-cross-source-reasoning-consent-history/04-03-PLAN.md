  <action>
    1. Add `AuditFinding` and `AuditReport` types to `src/reasoning/types.ts`:
       - `AuditFinding`: { id: string; category: 'unused-permission' | 'old-consent' | 'changed-policy'; severity: 'high' | 'medium' | 'low'; title: string; description: string; event: ConsentEvent; metadata: Record<string, unknown>; detectedAt: string }
       - `AuditReport`: { findings: AuditFinding[]; generatedAt: string; summary: { unusedCount: number; oldCount: number; changedCount: number } }

    2. Update `src/history/consent-history.ts`:
       - Add `policyHash` field to StoredPageView (hash of policy/terms content for change detection)
       - Add `getPageViewsWithPolicyHash(): Promise<StoredPageView[]>`
       - Add `updatePolicyHash(pageViewId, newHash): Promise<void>`

    3. Create `src/reasoning/audit-analyzer.ts` with `AuditAnalyzer` class:
       - Constructor takes `ConsentHistory` instance
       - `generateAudit(): Promise<AuditReport>`
       - **Unused permissions**: 
         - Query all granted events (grantStatus === 'granted')
         - For each, check if same capability+domain appears in recent pageViews (last 30 days) as *requested* but not *exercised*
         - Heuristic: if granted >90 days ago and no matching request in last 30 days → unused
         - Severity: high (sensitive: location, drive, camera), medium (contacts, photos), low (analytics)
       - **Old consents**:
         - Query all events with timestamp >90 days ago
         - Filter to grantStatus === 'granted' or 'pending'
         - Severity based on sensitivity of capability
       - **Changed policies**:
         - For each stored pageView with policyHash, re-fetch policy/terms (or use CrossSourceAnalyzer on current page)
         - Compare new hash with stored hash
         - If different → changed-policy finding with both hashes
         - Note: actual re-fetch happens in Phase 5; here we provide the comparison logic

    4. Update `src/reasoning/index.ts` to export AuditAnalyzer, AuditFinding, AuditReport

    5. Write tests in test/reasoning/audit-analyzer.test.ts:
       - Mock ConsentHistory with test data
       - Unused permission: granted drive access 100 days ago, no recent drive requests
       - Old consent: granted location 120 days ago
       - Changed policy: stored hash != current hash
       - Summary counts correct
       - Severity assignment per sensitivity
