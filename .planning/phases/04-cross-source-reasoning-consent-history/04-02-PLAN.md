## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Page content → ContradictionDetector | Untrusted policy/terms text analyzed for contradictions |
| ConsentHistory → IndexedDB | Local storage writes; user data never leaves browser |
| ConsentHistory queries → UI | Query results displayed in side panel history/audit views |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-04 | Tampering | ContradictionDetector keyword matching | low | mitigate | Use phrase lists + context; avoid false positives; evidence required for flag |
| T-04-05 | Information Disclosure | IndexedDB consent history | medium | mitigate | Data stays local; no sync; clear API for user data deletion |
| T-04-06 | Denial of Service | IndexedDB quota exceeded | low | mitigate | Cap stored events (e.g., 10k); LRU eviction; user can clear |
| T-04-07 | Elevation of Privilege | IndexedDB access from compromised content script | low | accept | Extension architecture isolates storage to background worker |
