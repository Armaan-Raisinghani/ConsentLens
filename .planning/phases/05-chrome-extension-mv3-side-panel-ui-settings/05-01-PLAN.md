<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Content script → Background | Untrusted page content could send malformed messages |
| Page DOM → Content script | Malicious page could craft DOM to trigger false consent events |
| Background → Side panel | Background could send excessive data to side panel |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Spoofing | content.ts message sending | medium | mitigate | Validate message origin; only accept messages from extension context |
| T-05-02 | Tampering | content.ts DOM extraction | medium | mitigate | Sanitize extracted data; limit evidence text length; validate capability structure |
| T-05-03 | Denial of Service | content.ts adapter loops | low | mitigate | Timeout on adapter execution; max events per page limit |
| T-05-04 | Information Disclosure | background.ts event storage | low | accept | Events stored in memory only, cleared on tab close |
| T-05-SC | Tampering | npm installs | high | mitigate | Package legitimacy audit in RESEARCH.md; blocking human checkpoint for [ASSUMED]/[SUS] |
</threat_model>
