## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Side panel → Background | User actions (Allow Once, Deny, pack change) sent to background |
| Background → DecisionEngine | Rule strings from user actions parsed and evaluated |
| Background storage → Memory | Tab decisions stored in memory, cleared on tab close |

| T-05-06 | Tampering | background.ts user rules | medium | mitigate | User rules only affect current profile; validated via parseRule before adding |
