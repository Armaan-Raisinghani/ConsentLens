    2. Add `RuleSet` interface: { layer: PrecedenceLayer, rules: ParsedRule[] }
    
    3. PrecedenceEngine constructor takes RuleSet[] (ordered by precedence: user first)
    
    4. `evaluate(event: ConsentEvent, matcher: RuleMatcher): EngineDecision`:
       - Iterate layers in order: user → trusted → community → defaults
       - Within each layer, iterate rules in order (first match wins per layer)
       - For each rule, use matcher.matchRule(rule, event)
       - Track if an exception (@@) was encountered that would allow
       - Exception logic (ENGINE-05): 
         - When exception rule matches (isException=true), it OVERRIDES any higher-precedence deny
         - Exception only applies to the specific capability@domain it matches
         - Exception action is implicitly 'allow'
       - Return first non-exception match from highest-precedence layer that has a match
       - If only exceptions match, return 'allow'
       - If no matches, return 'ask' (default action per uBlock)
    
    5. EngineDecision includes: decision, matchedRule, matchedLayer, explanation, confidence
    
    6. Write tests in test/engine/precedence-engine.test.ts:
       - User allow overrides trusted deny
       - User deny overrides trusted allow
       - Exception (@@) overrides user deny for specific capability@domain
       - Exception does not override user deny for different capability
       - Community rules apply when no user/trusted match
       - Defaults apply when no other layer matches
       - First-match-wins within same layer
  </action>
