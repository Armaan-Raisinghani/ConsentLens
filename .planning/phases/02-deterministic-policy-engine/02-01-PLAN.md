       - Parse `capability@domain = action` format (per ENGINE-01)
       - capabilityPattern: string (e.g., "oauth.google", "cookie.*")

       - Constructor takes rules: ParsedRule[]

       - Returns EngineDecision with decision, matchedRule, explanation, confidence=1.0

    - Suffix: `example.com` matches `sub.example.com`, `example.com` (per uBlock)
