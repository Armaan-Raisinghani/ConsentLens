  <action>
    Create the single entry point for the AI semantic layer:

    1. **src/ai/integration.ts** — AIIntegration class:
       - Constructor options:
         - `openjevApiKey?: string` — if provided, creates OpenJevClient; if not, uses fallback-only mode
         - `openjevBaseUrl?: string` — optional custom endpoint
         - `engines?: Partial<{ purpose, permission, policy, terms, mismatch }>` — for testing/custom engines
       - Internal: instantiates all 5 engines with shared OpenJevClient (or null for fallback)
       - `analyze(pageContext: PageContext, consentEvents: ConsentEvent[]): Promise<AIAnalysisResult>`
       - `AIAnalysisResult` interface:
         - `purpose: PurposeInference`
         - `permissions: PermissionInterpretation[]` (one per unique capability in events)
         - `policy: PolicyExtraction | null` (if policy events exist)
         - `terms: TermsExtraction | null` (if terms events exist)
         - `mismatches: MismatchReasoning[]` (one per event)
         - `openjevClassifications: OpenJevClassification[]` (one per event, from batch)
         - `summary: string` — cross-source natural language summary (AI-07)
         - `mode: 'openjev' | 'fallback'` — which mode was used
       - Pipeline steps:
         1. Infer purpose from pageContext
         2. Interpret permissions for each unique capability in consentEvents
         3. If policy events exist, extract policy (use first policy event's evidence.url)
         4. If terms events exist, extract terms (use first terms event's evidence.url)
         5. Run mismatch reasoning for all events against inferred purpose
         6. Run OpenJev batch classification for all events (if OpenJevClient available)
         7. Generate cross-source summary from purpose + mismatches + classifications
         8. Return AIAnalysisResult
       - Error handling: any engine failure → log, use fallback for that engine, continue pipeline
       - `getMode(): 'openjev' | 'fallback'`

    2. **src/ai/index.ts** — Export AIIntegration, AIAnalysisResult, all engines, OpenJevClient, OpenJevAIBackend, FallbackHeuristics
