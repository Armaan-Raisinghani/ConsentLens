       - Constructor takes `openjevClient?: OpenJevClient` (optional for fallback-only mode)
       - `infer(pageContext: PageContext): Promise<PurposeInference>` — PageContext from Phase 1 adapters (document, url, origin, metadata)
       - Extraction strategy:
         - Meta tags: `description`, `og:description`, `twitter:description`, `application-name`
         - Headings: `h1`, `h2` text content
         - Main content: `main`, `article`, `[role="main"]` text content (first 2000 chars)
         - Title: `document.title`

       - OpenJev question (choice type): "What is the primary purpose of this page?" with criteria: { "productivity": "Document editing, project management, developer tools", "social": "Social networking, messaging, content sharing", "ecommerce": "Shopping, payments, marketplace", "content": "Media consumption, news, entertainment", "auth": "Login, signup, account management", "other": "Other purpose" }
       - Fallback: keyword-based classification (e.g., "dashboard"→productivity, "feed"→social, "cart"→ecommerce)
       - Evidence: DOM selectors for each extracted element, text spans, confidence based on match strength
       - Returns PurposeInference with inferred, stated (from policy if available), userIntent (from context), confidence, evidence[]

    2. **src/ai/permission-interpretation.ts** — PermissionInterpretationEngine class:
       - Constructor takes `openjevClient?: OpenJevClient`
       - `interpret(capability: Capability): Promise<PermissionInterpretation>` — capability from Phase 1 taxonomy
       - Human description generation:
         - OAuth: "Access to your Google Drive files" (from scope map in ProviderRegistry)
         - Browser permission: "Access to your precise location" (from permission name)
         - Cookie: "Tracking cookie for advertising analytics" (from category + tracker list)
         - Policy: "Data collection for service improvement" (from practice)
         - Terms: "Binding arbitration clause limiting legal recourse" (from clause)
       - Sensitivity rating via OpenJev (score 0-2): "How sensitive is this permission?" criteria: ["Low: Anonymous analytics, non-identifying preferences", "Medium: Account access, contact info, non-sensitive files", "High: Precise location, camera/mic, financial data, private messages"]
       - Fallback: rule-based sensitivity (OAuth drive/calendar=high, analytics cookie=low, etc.)
       - Evidence: OAuth URL with scope, permission name, cookie name/domain, policy section, terms clause
       - Returns PermissionInterpretation with capability, description, sensitivity, evidence[]

    3. **src/ai/fallback-heuristics.ts** — FallbackHeuristics class (OPENJEV-06):
       - Static methods for each engine's fallback logic (no OpenJevClient dependency)
       - `inferPurpose(pageContext): PurposeInference` — keyword matching on extracted text
       - `interpretPermission(capability): PermissionInterpretation` — capability-type-based rules
       - `extractPolicy(text): PolicyExtraction` — regex/keyword extraction for practices, AI training, retention
       - `extractTerms(text): TermsExtraction` — regex/keyword extraction for clause types
       - `reasonMismatch(events, purpose): MismatchReasoning[]` — capability-vs-purpose keyword matching
