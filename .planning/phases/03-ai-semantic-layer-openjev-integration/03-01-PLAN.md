    3. **src/ai/openjev-types.ts** — Codiv API request/response types:
       - `OpenJevRequest` — { model: 'openjev-latest', state: string, questions: Record<string, NouQuestion | ChoiceQuestion | ScoreQuestion> }
       - `NouQuestion` — { type: 'noul', instructions: string }
       - `ChoiceQuestion` — { type: 'choice', instructions: string, criteria: Record<string, string> }
       - `ScoreQuestion` — { type: 'score', instructions: string, criteria: string[] }
       - `OpenJevResponse` — { model: string, answers: Record<string, NouAnswer | ChoiceAnswer | ScoreAnswer>, usage: { input_tokens: number, output_tokens: number } }

       - `ChoiceAnswer` — { type: 'choice', choice: string, probabilities: Record<string, number>, confidence: number }
       - `ScoreAnswer` — { type: 'score', score: number, legend: Record<string, string>, probabilities: Record<string, number>, confidence: number }

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ConsentEvent → OpenJevClient | User consent data sent to external API (Codiv) for classification |
| OpenJev API response → Classification | External AI model output drives allow/ask/deny decisions |
| AI backend plugin → Engine | Third-party AI backends execute with access to consent data |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Information Disclosure | OpenJevClient API calls | medium | mitigate | Only send minimal consent context (capability, domain); no PII; user controls API key |
| T-03-02 | Tampering | OpenJev API response | high | mitigate | Validate response schema; confidence thresholds; fallback heuristics (OPENJEV-06) |
| T-03-03 | Denial of Service | OpenJev API unavailable | medium | mitigate | Timeout (10s); retry with backoff; fallback heuristics; circuit breaker pattern |
| T-03-04 | Elevation of Privilege | Custom AI backend plugin | medium | mitigate | Plugin runs in same origin; no elevated permissions; validate backend interface |
| T-03-SC | Tampering | npm installs | high | mitigate | Package legitimacy audit; blocking human checkpoint for [ASSUMED]/[SUS] |
